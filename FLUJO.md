# Localmente — flujo organizado

## Recorrido principal

`Splash screen` → `Login` → `Inicio` → `Buscar espacios` → `Filtros avanzados` / `Explorar mapa` → `Perfil del propietario` → `Chat con propietario` → `Calendario de reservas` → `Resumen y pago` → `Confirmación de pago`.

## Ramas

- **Comunicación:** desde una reserva o un espacio, la persona puede ir a `Mensajes / bandeja de entrada`.
- **Propietario:** `Onboarding propietarios` → `Inicio de verificación` → `Documento` → `Selfie / validación facial` → `Detalles del negocio` → `Estado final` → `Dashboard del propietario` → `Editar detalle del espacio`.

## Punto de entrada

Abrir [`index.html`](index.html) para ver el mapa visual y navegar a cada pantalla.

## Criterio usado

Se tomó la iteración `stitch_localmente_commercial_marketplace 6` como base porque es la que conserva el conjunto más completo de pantallas, incluyendo calendario y edición del espacio. Las iteraciones 5 y 7 se mantienen intactas como referencias.
